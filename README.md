# Proteomics-Based Tissue Classification Using Machine Learning

This project uses quantitative proteomics data to classify tissue types using supervised machine learning models.

## Aim
To compare machine learning classifiers for proteomics-based tissue classification and evaluate model performance.

## Methods
- Data preprocessing and filtering
- Feature scaling
- Dimensionality reduction using PCA and UMAP
- Classification using:
  - Support Vector Machine
  - Random Forest
  - Logistic Regression
- Hyperparameter tuning
- 5-fold cross-validation

## Results
The best-performing model achieved 82.9% classification accuracy.

## Skills Demonstrated
- Python
- pandas, scikit-learn
- proteomics data analysis
- supervised machine learning
- cross-validation
- model evaluation
- PCA/UMAP visualisation
